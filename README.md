# Mantenimiento Opticalia

Aplicativo web (una sola página) para inventario maestro, protocolos y hojas de vida de equipos. Usa Supabase como base de datos.

## Publicar en Render
1. Sube este repositorio a GitHub.
2. En Render: **New → Blueprint** (detecta `render.yaml`) o **New → Static Site**.
3. Si eliges Static Site: Build Command vacío, Publish Directory `.`
4. Render publica en `https://mantenimiento-opticalia.onrender.com` (o similar) y redespliega con cada push.
